## 1. Architecture Overview

### Framework & Build Systems
The `tysonshields.com` web presence is engineered with high-performance, resilient, zero-bloat architecture spanning two coordinated repositories:

1. **Primary Website (`Tyson-Shields-Personal-Website`)**:
   - **Framework:** Semantic HTML5, Vanilla Modern CSS3, modular progressive JavaScript.
   - **Static Site Generation (SSG):** Eleventy (`@11ty/eleventy` v3) compiling pages with Nunjucks templates and passthrough file copies into `_site/`.
   - **Asset Pipeline:** `esbuild` compiling and minifying `styles.css` to `styles.min.css`.
   - **Typography:** Self-hosted `Outfit` variable fonts (`fonts/outfit-400-latin.woff2`, `fonts/outfit-700-latin.woff2`), zero external Google Fonts or CDN requests.
   - **Deployment Target:** Cloudflare Pages with edge caching, automated GitHub Actions CI/CD deployment on push to `main`.
   - **Routing Strategy:** Static routes (`/index.html`, `/about.html`, `/career.html`, `/skills.html`, `/contact.html`, `/Tyson-Shields-Resume.html`). Reverse proxy edge rules in `_redirects` forward `/dashboard` and `/chat` to `https://dashboard.tysonshields.com`.

2. **Edge Workspace & Assistant (`dashboard`)**:
   - **Framework:** Cloudflare Workers runtime (`_worker.js`) paired with an optimized Next.js 16 (Turbopack) application and static dashboard UI.
   - **Domain:** Custom domain `dashboard.tysonshields.com` mapped directly to Cloudflare Worker `dashboard`.
   - **Access Control:** Protected behind Cloudflare Zero Trust Access (`tysonshields00.cloudflareaccess.com`) with strict origin validation and token authorization.

The portfolio embodies an **Apple-inspired dark aesthetic**: sleek, understated, typographic, and mathematically structured.

### Typography Standards
- **Font Family:** `'Outfit', system-ui, -apple-system, sans-serif`
- **Scale:**
  - Hero `<h1>`: `clamp(2.4rem, 5.5vw, 4.2rem)`, letter-spacing `-0.03em`, font-weight `800`.
  - Section `<h2>`: `clamp(1.75rem, 3.5vw, 2.6rem)`, letter-spacing `-0.02em`, font-weight `700`.
  - Card `<h3>`: `1.25rem`, letter-spacing `-0.01em`, font-weight `600`.
  - Body `<p>`: `1.05rem`, line-height `1.65`, font-weight `400`.
  - Kicker/HUD Badge: `0.72rem`, letter-spacing `0.1em`, uppercase, font-weight `700`.

### Spacing Units
- `--space-xs`: `0.25rem` (4px)
- `--space-sm`: `0.5rem` (8px)
- `--space-md`: `1rem` (16px)
- `--space-lg`: `1.5rem` (24px)
- `--space-xl`: `2.5rem` (40px)
- `--space-2xl`: `4rem` (64px)

### Responsive Breakpoints
- **Mobile Small:** `< 480px` (single column, full-width buttons).
- **Tablet / Mobile Large:** `< 768px` (hamburger nav active, collapsed multi-column grids).
- **Desktop Standard:** `768px` to `1200px` (standard container shell max-width `1180px`).
- **Wide Screens:** `> 1200px` (proportional padding, margins centered via `.section-shell`).

## 5. Development & Deployment Workflow

### Prerequisites
- Node.js 18+ / 20+
- npm

### Common Commands
```powershell
# Compile CSS with esbuild (Fast production bundle)
npm run build

# Build full static site with Eleventy SSG
npm run build:ssg

# Start local zero-dependency preview server
npm run preview

# Synchronize header, footer, and settings drawer across all pages
npm run format:pages

# Verify Cloudflare Pages edge health
npm run cf:status

# Purge Cloudflare edge cache worldwide
npm run cf:purge
```
